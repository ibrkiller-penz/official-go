# [의원실 확인 필요] 항목

게시 전에 아래 항목을 채우거나 확인해야 합니다.

- [ ] 사무실 주소, 전화번호 (`contact.phone`, `contact.address`)
- [ ] 수치 기준일: 약자와의 동행 7회, 소상공인 식당 봉사 30회 (`stats[].note`)
- [ ] 대표 성과 출처와 세부 활동 (`achievements[].source`)
- [ ] 노란우산공제 소득세 혜택 개정안의 법령 원문 기준 확인
- [ ] 뉴스 2건의 실제 제목 (`news[].title`)
- [ ] 지역 현안·공약 카드 (`issues`), 관할 동 정보
- [ ] 민원 폼 전송 주소 (`contact.endpoint`) 및 개인정보 처리 방식
- [ ] 개인정보처리방침 페이지 (`footer.privacyHref`)
- [ ] 이미지 전체 (Canva 제작본, `public/images/README.md` 참고)
- [ ] 유튜브 영상 ID (`video.youtubeId`)
- [ ] SNS 링크 (`footer.sns`)
- [ ] 선거 모드 사용 여부: 선관위 검토 전까지 비활성

## 로고·상징 사용 (국민의힘 시각 상징 매뉴얼 기준)
- [ ] 당 로고 사용 가능 여부를 의원실과 당 관리부서에 확인 (매뉴얼 46쪽 하단: 규정 외 사용은 관리부서와 협의)
- [ ] 승인 시 원본 파일(SVG/PNG)만 사용. 비율 변경, 기울임, 그림자, 색 변경, 다른 요소와 조합 금지
- [ ] 선거 관련 용품(어깨띠, 현수막, 버스 등, 39~44쪽)은 이 사이트에 쓰지 않음. 선거 모드 전환 시 선관위 검토 필요
- [ ] 로고 자리 확정 후 `Header`, `Footer`, `og.png`에 배치 (아직 미배치)

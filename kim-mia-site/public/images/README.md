# 이미지 자리 (Canva에서 내보낸 파일을 아래 이름으로 넣기)

없으면 회색 그라데이션 자리표시로 대신 보입니다. 권장 형식은 WebP입니다.

| 파일명 | 권장 크기 | 용도 |
|---|---|---|
| hero.webp | 1920×1080 | 첫 화면 대표 사진 (의원 사진 1컷) |
| og.png | 1200×630 | 카카오톡·SNS 공유 미리보기 |
| achv-1.webp ~ achv-4.webp | 1200×675 | 대표 성과 카드 4장 |
| news-1.webp, news-2.webp | 320×200 | 소식 목록 썸네일 |
| gallery-1.webp ~ gallery-4.webp | 800×800 | 현장 갤러리 |

- 사진 속 제3자(미성년자, 피해자, 유가족)는 동의 없이 쓰지 않습니다.
- 당 상징이나 로고는 의원실 CI 확인 후에만 넣습니다.
